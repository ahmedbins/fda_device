# The Friendly Guide

**How this website works, explained for people who have never touched code.**

This guide is a short book. It walks through everything — what the website does, where its information comes from, what the files in this project actually are, and how the site ends up on the internet — one small step at a time.

You do not need to know any programming. You do not need to install anything (until the very last chapter, and even that is optional). Every technical word is explained the first time it appears, and there is a [glossary](glossary.md) if you ever need a reminder.

## How to read it

Read the chapters in order. Each one builds on the one before it, and each ends with a link to the next. The whole thing takes maybe 45 minutes.

## Who this is for

- A colleague who uses the site and wants to understand what's behind it
- Someone curious how a real website gets built, using this one as the example
- A future teammate getting oriented before diving into the technical docs

When you finish and want the deeper technical detail, the [main README](../README.md) and the [docs folder](../docs/) pick up where this guide leaves off.
