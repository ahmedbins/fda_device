# Glossary

*[← Guide home](README.md)*

Every technical term used in this guide, in plain language. Alphabetical.

| Term | Meaning |
| --- | --- |
| **API** | A "service window" where programs (rather than people) ask a website questions and get structured answers back. See Chapter 3. |
| **Build** | The step that translates the developer-friendly source files into the plain, compressed files browsers actually run. |
| **Cloudflare Pages** | The hosting service that stores our finished files on servers worldwide and hands them to visitors. |
| **Commit** | One saved change in Git's history, with a unique fingerprint, a timestamp, and a description of what changed and why. |
| **CORS** | A browser security rule: JavaScript from one website may only fetch data from another site if that site explicitly allows it. The reason some FCC requests fail in the browser. |
| **CSS** | The file type that controls how a page *looks* — colors, spacing, layout. |
| **CSV** | The simplest spreadsheet file format — plain rows of comma-separated values. Excel opens it directly. What the site's "export" buttons produce. |
| **Deployment** | Uploading a finished build to the hosting service so the public site updates. Each one is kept in history and can be rolled back. |
| **FCC ID** | The code on any US radio-transmitting product: a grantee code identifying the company (Sonova USA's is `KWC`) plus a product code the company chooses. |
| **Git** | The tool that records every change ever made to the project — a shared folder with perfect memory and unlimited undo. |
| **GitHub** | The website where this repository is stored and shared. |
| **Grantee** | The FCC's word for the company holding an equipment authorization. |
| **HTML** | The file type that describes a page's *content and structure* — headings, tables, buttons. |
| **JavaScript** | The programming language browsers run; it makes pages interactive and fetches data. |
| **JSON** | The structured text format APIs answer in — labels and values in curly braces, made for programs to read. |
| **MDALL** | Health Canada's Medical Devices Active Licence Listing — the registry of devices licensed for sale in Canada. |
| **Monitoring** | The site's "what happened recently?" view for each source. Its counterpart is **Explorer**, the search view. |
| **Normalization** | Translating each source's vocabulary and formats into one consistent internal shape — while always keeping the original wording attached. |
| **npm** | The tool that downloads the project's third-party packages and runs its short commands (`npm test`, `npm run dev`). |
| **Node.js** | The program that runs JavaScript outside a browser; powers the build, tests, and local development server. |
| **openFDA** | The FDA's public API service — our source for registrations, 510(k) clearances, recalls, and adverse events. |
| **Provenance** | Where a piece of data came from. This site labels the source and retrieval time of everything it shows. |
| **Proxy** | A relay: our small server-side helper that forwards FCC questions when the browser can't ask directly. |
| **React** | The toolkit used to build the screens out of reusable components, keeping the display in sync with the data. |
| **Repository (repo)** | A project stored in Git/GitHub — the files plus their entire history. |
| **Server** | A computer whose job is to answer requests over the internet — for files, or for data. |
| **Snapshot** | An exact saved copy of a real official FCC response, bundled with the site as a labelled last-resort data source for confirmed scopes. |
| **Static site** | A website that is just files — no database of its own. Ours fetches all live data from government APIs after the page loads. |
| **Test (automated)** | A small program that checks the real code gives the right answer for a known case. Hundreds of them run on every change. |
| **TypeScript** | JavaScript with declared data shapes — the build fails if code mishandles them. The project's `.ts`/`.tsx` files. |
| **510(k)** | The FDA submission through which most medical devices get cleared for the US market; named after a section of US law. |
